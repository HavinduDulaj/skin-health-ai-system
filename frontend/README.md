# DermaSafe Frontend

Expo React Native mobile app for skin condition image detection.

## Run

1. Open [src/services/api.js](/D:/RP/skin-project/frontend/src/services/api.js) and replace `http://<YOUR_IP>:5000/api` with your backend machine IP.
2. Install dependencies:

```bash
npm install
```

3. Start Expo:

```bash
npx expo start
```
